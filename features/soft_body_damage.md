# Soft-body повреждения кузова

## Зачем

Сейчас кузов — это `RigidBody3D` с одним `BoxShape3D` и цельным GLB (`Model`). Столкновения есть у физики Godot, но визуально и по хендлингу машина не мнется: нет зон, нет деформации меша, нет потери аэро/света.

Нужен **локальный dent**, а не полноценный FEM: удар в угол мнёт этот угол, капот, крыло, бампер — без превращения всей модели в желе.

## Что есть сейчас

| Место | Состояние |
|-------|-----------|
| `vehicles/car_controller.gd` | Кузов rigid, `physics_material_override.friction/bounce = 0` (сцепление только шины) |
| `golf.tscn` / `volga.tscn` | Один `CollisionShape3D` + инстанс GLB |
| Контакты | `contact_monitor` не используется — удары не читаются скриптом |
| Визуал | `Model` цельный, клиренс двигает весь меш |

## Целевой пайплайн

```
контакт (точка, нормаль, импульс)
        → зона кузова (перед / крыло L/R / дверь / зад / крыша)
        → накопленный dent в локальных координатах кузова
        → (опционально) GPU/CPU смещение вершин меша
        → вторичные эффекты: фары, бампер, Cd, max_steer
```

Godot 4 **не даёт** готовый soft-body для едущей машины. SoftBody3D плохо сочетается с нашим raycast-авто. Идём через **vertex displacement** (шейдер или `ArrayMesh`) + импульсы с `RigidBody3D`.

## Этапы

### 1. Сбор ударов

- Включить `contact_monitor` / `max_contacts_reported` на `CarController` **или** отдельный `Area3D`/колбэк `_integrate_forces` с `get_colliding_bodies()`.
- Фильтровать контакты с землёй (шина/рейка уже держат машину) — считать только стены, столбы, другие машины.
- Порог: импульс / относительная скорость, чтобы не мять кузов на мелких касаниях подвески.
- Debug: F3-маркеры точек удара.

### 2. Зоны кузова (без нарезки GLB сразу)

Словарь зон в `CarSetup` или отдельный `CarBodyLayout`:

- локальный AABB / капсула на бампер, капот, каждое крыло, двери, крыша, зад
- `health` 0..1, `plastic` vs `metal` (разный recovery)
- якоря фар уже есть в `CarLights` (`Headlights/Left` и т.д.) — привязать поломку света к передней зоне

Пока модель цельная: зона только логическая. Позже якоря совпадут с отдельными мешами тюнинга.

### 3. Визуальная деформация (soft look)

Порядок от простого к сложному:

1. **Blend / нормаль-офсет в шейдере** — карта dents как несколько сфер в локале кузова (`uniform vec4 dent0..N`), смещение вершин по нормали. Дёшево, хорошо для «вмятин».
2. **CPU ArrayMesh** — копия `ArrayMesh` при старте, смещение вершин в радиусе удара с falloff. Нужен доступ к surface arrays GLB (импорт `Meshes` как отдельные или `SurfaceTool`).
3. **Не делать** настоящий SoftBody3D / ткань на кузове — конфликт с `RigidBody3D` и raycast-колёсами.

Ограничения:

- не мять колёсные арки так, чтобы меш пролез в шину
- потолок смещения (см), иначе модель ломает нормали
- пластиковый бампер — сильнее мнется, слабее «пружинит»

### 4. Влияние на физику (мягкое)

Не ломать sim-ядро. Только множители в `CarSetup` runtime:

- смятый перед → чуть выше `drag_coefficient`, ниже `downforce`
- мёртвая фара → `CarLights` выкл
- сильный удар в колесную арку → чуть снизить `max_steer_angle` / ход подвески этой стороны
- **не** менять массу и CoM каждый кадр

### 5. Ремонт / сейв

- Гараж или кнопка «починить» в паузе (dev)
- Состояние dents в `user://` рядом с `tuning_<car>.cfg`
- Полный ресет = исходный меш + health 1

## Файлы, которые появятся / изменятся

- `vehicles/car_damage.gd` — сбор контактов, зоны, health
- `vehicles/car_body_layout.gd` или секция в `CarSetup`
- шейдер `shaders/car_dent.gdshader` **или** `vehicles/car_mesh_deform.gd`
- хук в `car_controller.gd` (`_integrate_forces` / сигнал удара)
- `car_lights.gd` — выключение по зоне
- F3 в `car_debug_draw.gd`

## Риски

- GLB с отрицательным scale (Volga) ломает нормали деформации — править в Blender до шейдера
- Один box-коллайдер даёт грубую точку удара; позже convex по частям кузова
- Слишком много CPU-вершин на 2 машинах ок, на NPC — только шейдер/билборды

## Приёмка

- [ ] Удар в стену на 40+ км/ч оставляет видимую вмятину в месте контакта
- [ ] Повторный удар рядом углубляет ту же зону, а не мнёт всю машину
- [ ] Фары тухнут при сильном переднем ударе
- [ ] Хендлинг чуть тупее (Cd), но машина едет
- [ ] Ремонт возвращает меш и свет
