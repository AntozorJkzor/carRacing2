# Открытый мир

## Зачем

Сейчас мир — одна сцена `physics_test_track.tscn`: `mountainRoad.glb`, две машины, игрок пешком, миникарта, пауза. Нет стриминга, нет POI, нет нескольких локаций, нет сохранения позиции в мире.

Открытый мир здесь — **одна большая карта с подгрузкой кусков**, а не MMO. Пешком + машины уже есть (`PlayerController` / `CarController.occupied`).

## Что есть сейчас

| Место | Состояние |
|-------|-----------|
| `assets/scenes/tracks/physics_test_track.tscn` | Единственный геймплей-уровень |
| `main_menu.gd` | «Новая игра» → эта сцена целиком |

| Чекпоинты / круги | Вырезаны |
| Автозагрузка | `TuningStore`, `GameAudio` — не мир |
| Пеший выход | Raycast на землю (`player_controller.gd`) |

Трек уже «большой кусок ландшафта», не овал. Проблема — всё в одной сцене: свет, коллизии, GLB, машины.

## Целевая схема

```
WorldRoot (autoload или главная сцена)
  ├─ TerrainStreamer     — чанки ландшафта / дорог
  ├─ PropStreamer        — дома, ограды, деревья
  ├─ Traffic / parked    — позже
  ├─ Player + cars       — не выгружать с чанком
  ├─ PersistentPOI       — гараж, заправка (всегда или отдельный слой)
  └─ HUD / Pause / Minimap
```

Игрок и занятая машина **не принадлежат чанку**. Чанки — только статика.

## Этапы

### 1. Разрезать контент карты

- В Blender/`mountainRoad` (или новый ландшафт): сетка чанков N×N метров (например 128–256 м)
- Каждый чанк: меш + коллизия (`StaticBody3D`) + опционально пропы
- Именование: `chunk_x_z.tscn` или один GLB с несколькими мешами + оффсеты
- Origin мира = 0, высота как сейчас (не Y=0) — выход из машины уже snap’ается raycast’ом

Пока нет нарезки: логический стример с **одной** подложкой и невидимыми bounds — чтобы отладить загрузку без арта.

### 2. Стример

- `world/chunk_streamer.gd`: по позиции игрока/машины грузить соседние 3×3 (или 5×5)
- `PackedScene.instantiate` / `queue_free` с гистерезисом, чтобы не thrash на границе
- Коллизии чанка должны появиться **до** того, как машина туда въедет (подгрузка с запасом)
- Миникарта: либо низкополигональный обзор всего мира, либо только загруженные чанки + спрайт-карта

### 3. Точки интереса

Минимальный набор для «мира», а не пустой ландшафт:

- **Спавн / гараж** — ремонт кузова, внешний тюнинг, смена машины из каталога
- **Дороги** с тем же физическим материалом, что трасса (шины завязаны на µ, не на surface ID — позже surface)
- Опционально заправка / смотровая — маркеры `Area3D` + UI prompt (как `interact` для посадки)

Данные: `world/world_pois.tres` (позиция, тип, сцена оверлея).

### 4. Сохранение мира

Отдельно от `tuning_*.cfg`:

- `user://world_save.cfg`: позиция игрока или последней машины, occupied car_id, yaw
- «Продолжить» в главном меню (кнопка уже обсуждалась) грузит мир + restore transform
- «Новая игра» сбрасывает позицию на гараж, тюнинг машин не трогает

### 5. Производительность и графика

- `GraphicsConfig` уже есть — добавить far fog / `camera.far` под размер мира
- `FollowCamera.far` сейчас 800 — мало для открытой карты
- Солнце одно (`DirectionalLight3D`) — ок; lightmap на едущих машинах не нужен
- NPC-трафик не в первой версии (убивает CPU шин)

### 6. Навигация игрока

- Пешком по чанкам: те же WASD, гравитация CharacterBody
- Посадка в любую машину в радиусе (`player_cars`) — уже работает, если машины не выгружать
- Застрявшие авто за границей стрима: либо не выгружать occupied, либо телепорт чанка под них

## Риски

- Один огромный GLB без чанков = стример бесполезен
- Дыры на швах чанков (щели коллизии) → провал под текстуры, как со старым Y=0
- Две машины + игрок на стыке четырёх чанков — пик инстансов
- Физика Godot и наши substeps не любят телепорты — restore позиции через `PhysicsServer3D.body_set_state`, как `reset_to_spawn`
