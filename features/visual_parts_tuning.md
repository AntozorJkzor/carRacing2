# Тюнинг внешних деталей

## Зачем

Сейчас «тюнинг» — это физика и звук через `CarSetup` + `TuningStore` (`user://tuning_<id>.cfg`). Внешне машина не меняется: цельный GLB, колёса отдельно (`VisualWheels` + `*_wheel.tscn`), фары — маркеры.

Нужен **конструктор внешнего вида**: бамперы, пороги, спойлер, капот, диски, тонировка — со слотами, пресетами и сохранением.

## Что есть сейчас

| Система | Роль |
|---------|------|
| `assets/scenes/cars/<id>/` | Пак: сцена, `*_setup.tres`, колесо, аудио |
| `vehicles/cars_catalog.tres` | Список машин |
| `vehicles/visual_wheels.gd` | Только шины/диски как отдельный меш |
| `vehicles/car_lights.gd` | Маркеры фар, не сменные корпуса |
| `assets/scenes/ui/settings_menu.gd` | Слайдеры физики, не визуальных слотов |
| GLB | Один `Model` на Golf / Volga |

Колёса уже отделены от кузова — это правильный паттерн для остальных деталей.

## Целевая модель слотов

Каждая машина в паке описывает **слоты**, а не хардкод «спойлер Golf»:

| Слот | Примеры | Влияние на физику (позже) |
|------|---------|---------------------------|
| `bumper_front` / `bumper_rear` | сток, спорт, оффроуд | Cd, лёгкий вес |
| `skirts` | нет / низкие | чуть Cd |
| `spoiler` | нет / лип / большой | `downforce_coefficient` |
| `hood` | сток / воздухозаборник | визуал + опционально звук |
| `mirrors` | сток / карбоновые | почти нет |
| `wheels` | уже есть сцена колеса | радиус/ширина → `CarSetup` ISO |
| `paint` / `wrap` | цвет albedo, позже декали | нет |
| `windows` | тонировка alpha | нет |
| `lights_housing` | сток / тёмные | только вид, логика света та же |

Пустые слоты = стоковая геометрия внутри базового GLB **или** скрытые меши в сцене.

## Этапы

### 1. Нарезка моделей (контент, не код)

Для Golf и Volga в Blender:

- вынести бамперы / спойлер / капот в отдельные объекты **или** оставить сток в кузове и добавить addon-меши поверх
- origin слота = точка крепления в локале кузова (как `CarLights/Headlights/Left`)
- единый scale с `Model` (Golf 3.5, Volga 4.5 — не забыть)
- Volga: убрать отрицательный scale корня GLB, иначе addon-детали вывернутся

Пока нет нарезки — можно прототип на примитивах (`BoxMesh` спойлер) чтобы отладить слоты.

### 2. Данные

Новые ресурсы:

- `vehicles/car_part.gd` — `id`, `slot`, `scene`, `display_name`, опционально дельты `CarSetup` (Cd, Cl, mass)
- `vehicles/car_parts_catalog.tres` — список деталей
- в `CarDefinition` или рядом: какие слоты есть у этой машины и стоковые `part_id`

Сохранение: секция `[visual_parts]` в `user://tuning_<car>.cfg` (`spoiler=lip`, `paint=...`).

### 3. Рантайм-сборка

- Нода `VisualParts` на паке машины (рядом с `VisualWheels`)
- При старте / смене слота: `queue_free` старый инстанс, `instantiate` новый в Marker слота
- Сток: либо ничего не инстансить (геометрия в кузове), либо всегда инстансить `stock_*` и прятать кузовные куски по имени меша

Имена маркеров: `PartSlots/BumperFront`, `PartSlots/Spoiler`, …

### 4. UI

Не смешивать со слайдерами двигателя. Отдельный экран «Внешний вид» в хабе настроек / паузе:

- список слотов
- превью (можно `SubViewport` с машиной, как миникарта)
- цвет кузова: `StandardMaterial3D.albedo_color` на именованном surface (нужен материал «Paint» в GLB)
- «Применить» пишет cfg и зовёт `VisualParts.rebuild()` без перезагрузки сцены

### 5. Связь с физикой (после визуала)

Только явные дельты с детали, не магия:

- большой спойлер → `downforce_coefficient += …`
- широкий бампер → `frontal_area` / Cd
- смена диска уже почти есть через ISO в `WheelLayout` / `CarSetup`

Не перезаписывать весь `CarSetup` — аддитивный слой поверх стока, как clearance.

## Файлы

- `vehicles/car_part.gd`, `vehicles/car_parts_catalog.tres`
- `vehicles/visual_parts.gd`
- маркеры в `golf.tscn` / `volga.tscn`
- `assets/scenes/ui/` — экран внешнего тюнинга
- `tuning_store.gd` — секция visual parts
- контент: `assets/models/cars/<id>/parts/`

## Риски

- Цельный GLB без слотов = нельзя «снять» стоковый бампер, только надеть поверх (выглядит плохо)
- Разный pivot в Blender → детали висят в воздухе
- Перекраска: если albedo зашит в текстуру, нужен отдельный paint-mask канал

## Приёмка

- [ ] На Golf можно поставить/снять спойлер без рестарта сцены
- [ ] Выбор сохраняется в `tuning_golf.cfg` и поднимается при входе
- [ ] Колёса по-прежнему крутятся через `VisualWheels`
- [ ] Спойлер даёт заметный (настраиваемый) прирост прижима
- [ ] Volga и Golf имеют независимые каталоги совместимых деталей
